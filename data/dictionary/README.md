# معجم Student DZ العربي — المساهمة والبيانات

## الحالة الحالية
قاعدة تمهيدية تضم 95 مدخلًا عربيًا بتعاريف موجزة محررة للمشروع (CC0-1.0). الحقول `reviewed: false` تبيّن أنها **لم تخضع لمراجعة معجمية متخصصة**. لا يُفترض أن كل مدخل يملك أضدادًا أو مرادفات مناسبة في جميع السياقات. لا يُنسب هذا المحتوى إلى ويكاموس أو أي معجم آخر.

## التصميم
`index.json` يربط الحروف بالملفات. تُحمّل الواجهة الملفات عند الحاجة، ويمكن تخزينها عبر Service Worker للعمل دون اتصال بعد زيارة الموقع. لكل مدخل `id, word, root, pos, senses[], synonyms[], antonyms[], source, reviewed`. تُفهرس كلمات البحث بعد إزالة التشكيل والتطويل وتوحيد صور الهمزة، مع إبقاء نصوص العرض الأصلية.

## التوسع
يمكن استيراد بيانات مصدر مرخّص باستخدام `scripts/import-arabic-dictionary.py`. يقبل السكربت JSONL مع حقول `word` و`senses` (تعريف عربي لكل معنى)، ويدعم شكل Kaikki/Wiktionary مع تحويل `glosses` وتصفية الشروح غير العربية. راجع النسخة والترخيص الفعلي للمصدر قبل التنزيل؛ أضف بيانات الإسناد ورابط المصدر وصفحة الشروط إلى الموقع إذا استُخدمت بيانات CC BY-SA، ولا تفترض أن بيانات WordNet يمكن دمجها وترخيصها بنفس رخصة التعريفات الأصلية. **لا** تشغّل الاستيراد على الملفات المنشورة دون تدقيق عينة ومراجعة ملف `licenses.json`؛ الأفضل إخراج البيانات إلى مجلد عمل مستقل ثم مراجعتها قبل الرفع. المحتوى المستورد يبقى `reviewed: false` حتى يراجعه محرر لغوي.

## التحقق
1. افتح `tools/arabic-dictionary.html` من خادم محلي أو GitHub Pages (وليس عبر `file://`).
2. جرّب البحث عن «إجتهاد» و«اجتهاد»، والجذر «ج ه د» ثم تصفح حرف «ع».
3. اختبر المفضلة وسجل البحث وإعادة التحميل، وجرّب Quiz.
4. افتح Developer Tools واختبر عدم وجود 404 عند تحميل البيانات. جرّب الهواتف بعرض 320px، والوضع الليلي والتنقل بلوحة المفاتيح.
5. بعد تحميل الصفحة مرة متصلة، فعّل وضع Offline وأعد زيارتها. إذا لم يُثبّت Service Worker بعد، قد يتطلب إعادة تحميل أولى عبر الإنترنت.

ملاحظة: لا توجد حصة API أو مفتاح سري للقاموس. النطق يستخدم أصوات الجهاز وقد لا تتوفر العربية في بعض المتصفحات.
